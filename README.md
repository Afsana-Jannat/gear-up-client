# 📖 Overview

GearUp is a modern equipment rental platform that connects **Customers**, **Providers**, and **Administrators** in one seamless application.

Customers can browse sports & outdoor equipment, rent items securely through Stripe, track rental progress, and submit reviews.

Providers manage their inventory and rental requests, while administrators oversee users, categories, gear, and rental activities from a centralized dashboard.

# 🔧 Installation

Clone the repository

```bash
git clone https://github.com/Afsana-Jannat/gear-up-client
```

Install dependencies

```bash
npm install
```

Configure environment variables

```env
NEXT_PUBLIC_BACKEND_API_URL=https://gear-up-vlxn.onrender.com
BACKEND_API_URL=https://gear-up-vlxn.onrender.com
```

Run locally

```bash
npm run dev
```
